# Hisaab website

Static site served by GitHub Pages from `main`.

- `index.html`: landing page (light animation via Motion from jsDelivr, `main.js`)
- `privacy/index.html`: privacy policy for the Google Play build
- `styles.css`: shared mint and sky styles

No build step. Preview locally with `python3 -m http.server` and open http://localhost:8000.
